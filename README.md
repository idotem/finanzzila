## 🏦 A Modern UI Budget App

**Finanzzila** is a sleek and intuitive budgeting application designed to help you take control of your finances. With an easy-to-use interface, you can configure spending categories and effortlessly import transactions from `.xlsx` files. Finanzzila automatically categorizes your expenses, giving you a clear overview of where your money is going.

---

## ✨ Features
- **Custom Categories** – Define and manage your spending categories with ease.
- **XLSX File Upload** – Import transactions from your bank statements in `.xlsx` format.
- **Automatic Categorization** – Let Finanzzila sort your expenses for better financial insights.
- **Modern UI** – A clean and user-friendly interface for effortless budget tracking.

## 🚀 Getting Started
### Prerequisites
- Node.js & npm (for frontend)
- NestJS (for backend)

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/idotem/finanzzila.git
   cd finanzzila
   ```
2. Navigate to the backend and install dependencies:
   ```sh
   cd backend
   npm install
   ```
3. Navigate to the frontend and install dependencies:
   ```sh
   cd ../frontend
   npm install
   ```
5. Navigate back to /finanzzila and run:
   ```sh
   cd ..
   npm run start
   ```
